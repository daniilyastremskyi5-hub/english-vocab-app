Цветовые Токены (Design Tokens)

Основа дизайн-системы Liquid Glass — это тщательно подобранные, мягкие и контрастные цвета. Все цвета выражены через CSS Custom Properties и используют современный формат oklch или стандартный rgba для прозрачностей. Кликните на карточку любого цвета, чтобы скопировать его переменную или hex-значение.

Спецификация Glassmorphism (Стекло)

Вся эстетика Liquid Glass строится на "живом" размытии заднего фона с эффектом матового остекления. Чтобы эффект выглядел премиально и не мешал чтению, соблюдаются строгие правила наложения теней, белых полупрозрачных границ и степени размытия.

layers_clear Спецификация Слоя матового стекла (Glass Layer)

1. Задний фон (Background Gradient)

Стекло работает только на контрастном или цветном фоне. Фон приложения — это мягкий градиент:
linear-gradient(to bottom, #a0c4ff 0%, #d8e5ff 40%, #ffffff 100%).

2. Заливка стекла (Fill)

Для стандартной карточки (Glass Card): Чистый белый цвет с прозрачностью 45% (rgba(255, 255, 255, 0.45)).
Для интерактивных элементов при наведении/активных (Active/Strong): Белый цвет с прозрачностью 60% (rgba(255, 255, 255, 0.6)).

3. Размытие фона (Backdrop Blur)

Обязательное условие матовости — размытие контента под карточкой.
backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px);

4. Граница (Specular Highlight Border)

Тонкая светлая обводка имитирует блик на грани стекла.
border: 1px solid rgba(255, 255, 255, 0.70);

5. Тень (Soft Ambient Shadow)

Очень мягкая, размытая тень синего оттенка, которая не грязнит интерфейс:
box-shadow: 0 12px 32px rgba(48, 89, 185, 0.05);

Настройка системы дизайна в Figma

Чтобы проектировать новые страницы в Figma или любом другом графическом редакторе, вам нужно воссоздать эти эффекты и токены в качестве библиотек стилей.

tune 1. Глобальные Стили Цвета (Local Styles / Variables)

Создайте в Figma следующие цветовые переменные (Variables):

  • Primary Blue: #3059b9
  • Secondary Navy: #3d5f91
  • On Surface: #181c20
  • On Surface Variant: #434652
  • Outline: #747684
  • Outline Variant: #c4c6d4
  • Glass Fill: #FFFFFF (Прозрачность: 45%)
  • Glass Fill Strong: #FFFFFF (Прозрачность: 60%)
  • Background Gradient: Линейный градиент сверху вниз:
    • 0% — #a0c4ff
    • 40% — #d8e5ff
    • 100% — #ffffff
filter_frames 2. Воссоздание Матового Стекла (Glassmorphism Effect)

В Figma эффект матового стекла создается с помощью Effects и правильной настройки Stroke. Следуйте этой инструкции:

1
Создайте прямоугольник со скруглением
Скругление углов (Corner Radius) установите равным 24px или 28px.
2
Настройте заливку (Fill)
Цвет заливки: #FFFFFF, непрозрачность (Opacity): 45%.
3
Добавьте обводку (Stroke)
Обводка: толщина 1px, цвет #FFFFFF, непрозрачность: 70%, тип наложения: Inside. Это создает глянцевый блик по краям карточки.
4
Добавьте эффекты (Effects)
Примените два эффекта:
• Background Blur: размытие 20px (создает матовость заднего фона).
• Drop Shadow: цвет #3059B9 (основной синий), прозрачность: 5%, смещение по Y: 12px, размытие Blur: 32px.

Перенос дизайна в другое приложение

Чтобы скопировать этот интерфейс в другое веб-приложение или разработать новые страницы на чистом HTML/CSS, вам понадобится перенести базовую структуру стилей.

terminal 2. Интеграция с Tailwind CSS (Версия 4)

Если вы переносите дизайн в приложение, использующее Tailwind v4 (как текущее приложение на React/Vite), импортируйте переменные прямо в вашу тему в styles.css: 

@theme {
  --color-primary: var(--ll-primary);
  --color-secondary: var(--ll-secondary);
  --color-card: var(--glass-fill);
  --color-border: var(--glass-border);
  --radius-lg: 24px;
  --radius-xl: 28px;
}
